# LumeShot 长截图拼接改造规划

## 1. 目标

- 提升真实页面的重叠识别准确率。
- 减少错拼、重复和丢帧。
- 保持纯 Qt / C++17，不引入 OpenCV。
- 保持 `stitch::detectOverlap` 签名和返回语义不变。
- 不改 `ScrollSession`、UI、抓帧间隔。

## 2. 已确认决策

1. 横向抖动：检测到就拒绝该帧，不做补偿。
2. 反向滚动：丢弃该帧，不回退已截内容。
3. 空白和低纹理：判为不可靠，丢弃该帧。
4. 重复纹理歧义：取重叠最大的候选；列间结论冲突时丢帧。
5. 直接在 `main` 分支修改，不开分支。
6. 只借鉴开源项目思路，不复制代码。
7. 本次不改版本号。

## 3. 术语澄清

### 3.1 低纹理帧

- 画面大部分是纯色或留白。
- 没有足够证据确定偏移。
- 处理：返回 0，丢帧。
- 效果：长图会压缩空白区域。

需要注意：

- 空白超过一屏时，后续画面可能无法与旧锚点重叠。
- 后续纹理画面也可能被连续丢弃。
- 本次保持现状，不增加重新锚点逻辑。
- 后续可加「连续失败 N 帧后重新锚点」。

### 3.2 歧义帧

- 画面有纹理，但存在多个几乎一样吻合的偏移。
- 典型场景：重复表格行、相同卡片、图标列表。
- 和空白无关。
- 例：100 行重复图案，滚动 40 行。
- 重叠 260 和 160 都可能吻合。
- 处理：取重叠最大的候选，即 260。
- 各列结论互相冲突时丢帧。

## 4. 现状问题

- 整行缩成 1D 信号，多栏和图片区域信息被抹平。
- 使用绝对灰度差，整体亮度变化会拒识。
- 只取单一全局最优，重复纹理容易选错。
- 平坦行参与比对，大片留白稀释纹理证据。
- 固定页头参与比对会拉高误差。

## 5. 算法设计

### 5.1 帧描述子

- 灰度化后宽度缩到 96，高度保持不变。
- 缩放用最近邻，避免插值混合列。
- 横向三等分，左右各留 `min(3, w/12)` 边距。
- 每行每栏记录三个值：均值、加权均值、对比度。
- 平坦行用上下邻近行的纵向跨度补强对比度。

### 5.2 同一帧判定

- 先做全帧比对。
- 按列计算去均值后的平均绝对差。
- 阈值 1.5 灰阶。
- 命中则返回 -1，表示没有滚动。
- 去均值可以抵消整体亮度偏移。

### 5.3 粗筛

- 重叠范围：`max(16, h/20)` 到 `h - 1`。
- 每栏采样 32 行。
- 跳过两帧对比度都低于 20 的行。
- 行误差取均值差和加权均值差的平均。
- 列误差排序后取前 2/3 平均，丢掉最差 1/3。
- 每栏取前 3 名，各扩展 ±2，去重得到候选集。

### 5.4 精验

- 每栏采样 128 行。
- 行误差按逐像素绝对差计算。
- 逐行减去栏内均值，避免固定页头拉偏整列基线。
- 列误差排序后取前 2/3 平均。
- 单像素容差 6 灰阶，容忍抗锯齿。
- 允许相邻 ±1 偏移，容忍亚像素滚动。

### 5.5 可靠性判定

- 按列统计有纹理行的纵向跨度，作为列权重。
- 有效列条件：权重大于 0，且该列最小误差不超过 6。
- 有效列权重和必须超过总权重的一半。
- 不满足则返回 0。

### 5.6 候选仲裁

- 只保留各列误差通过、且相邻偏移一致的候选。
- 按列权重加权求误差。
- 误差相同或差值小于 0.5 时，取重叠最大的候选。
- 各列结论冲突到无法形成一致候选时，返回 0。

### 5.7 伪代码

```text
detectOverlap(tail, frame):
    if 尺寸不一致 or 宽 < 3 or 高过小: return 0

    prev = profile(tail)
    cur  = profile(frame)

    if 全帧去均值误差 < 1.5: return -1

    coarse = []
    for overlap in [minOverlap, height - 1]:
        coarse += {overlap, columnErrors(prev, cur, overlap, coarse=true)}

    candidates = 每列前 3 名各扩展 ±2 的并集

    checked = []
    for o in candidates:
        checked += {o, columnErrors(prev, cur, o, coarse=false)}

    minima[c] = min(checked[c])
    有效列 = 权重 > 0 且 minima[c] <= 6
    if 有效列权重和 <= 总权重/2: return 0

    agreeing = 加权误差通过的候选
    if agreeing 为空: return 0

    best = agreeing 中误差最小者
    若存在误差差 < 0.5 的候选: 取其中重叠最大者
    return best.overlap
```

## 6. 参数表

| 参数 | 初值 | 作用 |
| --- | --- | --- |
| 描述子宽度 | 96 | 控制成本 |
| 列数 | 3 | 结构信息与成本平衡 |
| 列边距 | `min(3, w/12)` | 排除滚动条 |
| 对比度阈值 | 20 | 区分平坦行 |
| 粗筛采样 | 32 | 快速筛候选 |
| 精验采样 | 128 | 稳定评分 |
| 像素容差 | 6 | 抗锯齿 |
| 权重门槛 | 50% | 低纹理拒识 |
| 同一帧阈值 | 1.5 | 亮度不敏感 |
| 歧义误差差 | 0.5 | 判定近似并列 |
| 最小重叠 | `max(16, h/20)` | 沿用 |
| 最大重叠 | `h - 1` | 支持 1px 滚动 |
| 性能目标 | 30ms | 1080p 单帧 |

参数集中放在 `stitch.cpp` 匿名命名空间。

## 11. 风险与回退

- 合成样本可能过拟合。
- 应对：阈值集中管理，保留真实样本接入点。
- 去均值可能削弱区分度。
- 应对：权重门槛和列间一致性兜底。
- 窄选区列划分可能退化。
- 应对：宽度不足时退化为单列。
- 性能可能超标。
- 应对：精验采样降到 64，候选数降到 3。
- 大段空白后可能丢失后续内容。
- 本次不处理，记录为已知限制。
- 重复纹理取最大重叠可能压缩内容。
- 这是已确认的取舍。

回退方式：还原 `stitch.cpp` 即可。
